The repository consists of an R project with 3 folders. For a detailed description of all the files, please see below. To run this repository, first download and unzip the entire repository and open the Rproject file: [meta-analysis_noise_fitness.Rproj](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/meta-analysis_noise_fitness.Rproj). The scripts are named in the order that they should be run, from 001 to 008. For any further information about this repository, please contact: [Alfredo Sánchez-Tójar](https://scholar.google.co.uk/citations?hl=en&user=Sh-Rjq8AAAAJ&view_op=list_works&sortby=pubdate), email: alfredo.tojar@gmail.com. 


## Information about folders and files within:

Folders:
-	[code](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/code): contains all scripts used for the project, as well as all models run and saved as .rds (folder: [models](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/models)).
 - - [001_systematic_review_process.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/001_systematic_review_process.R): written by LdF, AC and NPM, and used for the process of systematically reviewing the literature on noise effects on bird fitness.
 - - [002_data_cleaning.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/[002_data_cleaning.R]): used to clean and standardize the data collected by LdF, AC and NPM. 
 - - [003_effect_size_calculation.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/003_effect_size_calculation.R): used to import the cleaned database generated by script 002 and calculate all effect sizes required for the meta-analyses.
- - [004_phylogeny.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/004_phylogeny.R): used to import the cleaned database generated by script 003, revise the species names and generate both the phylogeny and its corresponding phylogenetic correlation matrix.
- - [005_mean_analyses_SMD_H.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/005_mean_analyses_SMD_H.R): used to import the final database generated by script 004 and perform the meta-analysis of means on SMD(H), which corresponds to most of the analyses presented in the main text.
- - [006_mean_analyses_lnRR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/006_mean_analyses_lnRR.R): used to import the final database generated by script 004 and perform the meta-analysis of means on lnRR, which checks the robustness of our main results when using a different effect size. These analyses are presented in the supplementary text.
- - [007_variance_analyses_lnCVR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/007_variance_analyses_lnCVR.R): used to import the final database generated by script 004 and perform the meta-analysis of variance on lnCVR, which corresponds to most of the analyses presented in the main text.
- - [008_variance_analyses_lnVR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/008_variance_analyses_lnVR.R): used to import the final database generated by script 004 and perform the meta-analysis of variance on lnVR, which checks the robustness of our main results when using a different effect size. These analyses are presented in the supplementary text.
- - [009_figures.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/008_figures.R): used to generate most of the figures provided in this study.

- [data](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/data): contains all data necessary to reproduce this study. The data is organised in four different folders.
- - [01_systematic_review](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/systematic_review): contains all data files related to the systematic review process
- - [02_master](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/master): contains the final master dataset as an .xlsx used for extracting the data
- - [03_raw](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/raw): cotains a .csv version of the master dataset, as well as a data dictionary for it
- - [04_processed](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/processed): cotains all processed .csv files generated through scripts 002 to 004, as well as the phylogeney and its corresponding correlation matrix in the folder phylogeny. Importantly, the final dataset used for the actualy meta-analyses is noisemeta_datasheet_processed_3.csv.

- [figures](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/figures): contains all figures generated in this study.
