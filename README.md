Alfredo Sánchez-Tójar, Nicholas P. Moran, Léna de Framond, Alberto Comin, Henrik Brumm. *In preparation*. **Noise as a global change driver: a meta-analysis of its fitness consequences for birds**.

The repository consists of an R project with 3 folders. For a detailed description of all the files, please see below. To run this repository, first download and unzip the entire repository and open the Rproject file: [meta-analysis_noise_fitness.Rproj](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/meta-analysis_noise_fitness.Rproj). The scripts are named in the order that they should be run, from 002 to 010. The scripts used for step 001, i.e., the literature review, are provided within the folder [01_systematic_review](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/systematic_review). For any further information about this repository, please contact: [Alfredo Sánchez-Tójar](https://scholar.google.co.uk/citations?hl=en&user=Sh-Rjq8AAAAJ&view_op=list_works&sortby=pubdate), email: alfredo.tojar@gmail.com. 

Pre-registration for this study available at: https://doi.org/10.17605/OSF.IO/HBPSF

## Information about folders and files within:

Folders:
-	[code](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/code): contains all scripts used for the project, as well as all models run and saved as .rds (folder: [models](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/models)).
 - - [002_data_cleaning.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/[002_data_cleaning.R]): used to clean and standardize the data collected by LdF, AC and NPM. 
 - - [003_effect_size_calculation.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/003_effect_size_calculation.R): used to import the cleaned database generated by script 002 and calculate all effect sizes required for the meta-analyses.
- - [004_phylogeny.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/004_phylogeny.R): used to import the cleaned database generated by script 003, revise the species names and generate both the phylogeny and its corresponding phylogenetic correlation matrix. It's important to note that during the conduction of this study, the package 'clootl' was updated and its syntax changed. Our code will run as it stands with clootl_0.1.2. 
- - [005_mean_analyses_SMD_H.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/005_mean_analyses_SMD_H.R): used to import the final database generated by script 004 and perform the meta-analysis of means on SMD(H), which corresponds to most of the analyses presented in the main text.
- - [006_mean_analyses_lnRR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/006_mean_analyses_lnRR.R): used to import the final database generated by script 004 and perform the meta-analysis of means on lnRR, which checks the robustness of our main results when using a different effect size. These analyses are presented in the supplementary text.
- - [007_variance_analyses_lnCVR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/007_variance_analyses_lnCVR.R): used to import the final database generated by script 004 and perform the meta-analysis of variance on lnCVR, which corresponds to most of the analyses presented in the main text.
- - [008_variance_analyses_lnVR.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/008_variance_analyses_lnVR.R): used to import the final database generated by script 004 and perform the meta-analysis of variance on lnVR, which checks the robustness of our main results when using a different effect size. These analyses are presented in the supplementary text.
- - [009_figures_1_Map.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/009_figures_1_Map.R): used to generate the map in this study.
- - [009_figures_2-3.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/009_figures_2-3_Map.R): used to generate the main text orchard plots in this study.
- - [010_sensitivity_analyses_main_effects.R](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/code/010_sensitivity_analyses_main_effects.R): used to run a bunch of sensitivity analyses to test the robustness of the results of this study.

- [data](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/data): contains all data necessary to reproduce this study. The data is organised in four different folders.
- - [01_systematic_review](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/systematic_review): contains all data files, including the code used, related to the systematic review process. The information in this folder was generated mostly by LdF with support from AC, and some post-hoc re-organisation by NPM.
- - [02_master](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/master): contains the final master dataset as an .xlsx used for extracting the data. Warning: this is not exactly the same as the data finally analysed as typos were corrected and additional decisions on eligible studies made during data processing
- - [03_raw](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/raw): contains a .csv version of the master dataset, as well as a data dictionary for it
- - [04_processed](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/processed): contains all processed .csv files generated through scripts 002 to 004, as well as the phylogeney and its corresponding correlation matrix in the folder phylogeny. Importantly, the final dataset used for the actualy meta-analyses is noisemeta_datasheet_processed_3.csv.

- [figures](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/tree/main/figures): contains all figures for this study.

## Data dictionary:
We provide a data dictionary file for the raw (master) dataset [Draft_noisemeta_datasheet_MASTER_20260705_Dictionary.csv](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/data/03_raw/Draft_noisemeta_datasheet_MASTER_20260705_Dictionary.csv), which we put together as we developed the data extract sheet template. This orignal dataset contains the original variables extracted during the data extraction phase, which are only a subset of all variables included in the processed dataset. The explanation for the remaining variables, which are, in most cases, updated versions of the original variables and that were generated through the scripts (002 to 008), is provided in a data dictionary that we have generated through an LMM based on script 002_data_cleaning.R, and a posteriori revised and extended whenever necessary to ensure validity, and is now provided in [noisemeta_datasheet_processed_1_data_dictionary_LMM.csv](https://github.com/ASanchez-Tojar/meta-analysis_noise_and_fitness/blob/main/data/04_processed/noisemeta_datasheet_processed_1_data_dictionary_LMM.csv).
